    Why this project: most portfolio pipelines run happy-path demos on toy data. This one migrates a real production system I built and operated — including the unglamorous parts: idempotent re-runs, file archiving, Windows path resolution, silent validation failures, and column-name mismatches that only surface on real files. Every bug is documented with its root cause and fix. Ingestion layer is complete and verified; the dbt transformation layer (replacing the original StgToTrn stored procedure) is the current milestone.
